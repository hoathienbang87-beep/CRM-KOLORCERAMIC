## 4. Hợp đồng API v1

### Danh sách/tìm kiếm/lọc/phân trang

RPC:

`catalog_public_list_products_v1(p_search, p_category, p_collection, p_surface, p_width_mm, p_height_mm, p_min_price, p_max_price, p_limit, p_offset)`

- Tìm kiếm theo tên, code, bề mặt, category, collection và description.
- Lọc chính xác theo category, collection, surface và kích thước có thứ tự.
- Lọc khoảng giá VNĐ/m².
- `limit` từ 1 đến 100; `offset` từ 0 đến 100.000.
- Trả `items` và `pagination` gồm `limit`, `offset`, `total`, `has_more`, `next_offset`.
- Thứ tự ổn định: tên chuẩn, width, height, surface, UUID.

### Chi tiết

RPC:

`catalog_public_get_product_v1(p_identifier)`

- Nhận UUID hoặc code hiện tại.
- Nhận source ID legacy verified nếu source ID chỉ trỏ tới đúng một published Product.
- Trả `null` cho mã không tồn tại, unpublished, draft hoặc archived.
- Không trả source mapping/provenance trong response.

### Public whitelist

`id`, `code`, `name`, `width_mm`, `height_mm`, `size_display`, `surface`, `origin`, `color`, `category`, `collection`, `description`, `image_url`, `gallery_urls`, `pdf_url`, `video_url`, `more_info_url`, `price_per_m2`, `price_unit`, `price_effective_date`.

`size_display` dẫn xuất từ mm sang cm, ví dụ `600 × 1200 mm` thành `60 × 120 cm`. Giá vẫn là số trong database/API để UI định dạng `vi-VN` thành dạng như `1.915.000`.
