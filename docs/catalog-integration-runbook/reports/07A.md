## 4. Hành vi đã hoàn thành

### Public API và state độc lập

- Gọi duy nhất `catalog_public_list_products_v1` với đủ tham số search, category, collection, surface, width/height mm, min/max price, limit và offset.
- Không có `.from(...)`, public detail RPC, website lead RPC hoặc catalog admin RPC trong website 07A.
- Supabase client public dùng anon config nhưng tắt `persistSession`, `autoRefreshToken` và `detectSessionInUrl`, không chia sẻ lifecycle auth CRM.
- Request cũ bị bỏ qua theo request counter khi người dùng thay bộ lọc nhanh.

### Tìm kiếm, lọc và pagination

- Search debounce 350 ms và submit thủ công.
- Filter theo danh mục, bộ sưu tập, bề mặt, năm quy cách thường dùng và ba khoảng giá.
- Quy cách UI theo cm được gửi tới API dưới dạng mm có thứ tự.
- Page size 12; nút `Xem thêm sản phẩm` là fallback hữu hình, `IntersectionObserver` tự nạp trang kế tiếp.
- Offset/total/has_more/next_offset lấy từ response 05A; thẻ đã render không bị lặp.

### Hiển thị và responsive

- Product card hiển thị collection/category, code, tên, quy cách cm, bề mặt, màu, xuất xứ và giá VNĐ/m².
- Giá dùng `Intl.NumberFormat("vi-VN")`, không thay đổi kiểu số của API/database.
- URL ảnh HTTP hoặc sai định dạng bị từ chối; URL HTTPS lỗi chuyển sang fallback và không làm vỡ grid.
- Skeleton loading, empty state, error/retry state và live result count đã có.
- Grid chuyển 4 cột desktop, 3 cột màn hình vừa, 2 cột mobile và 1 cột ở màn hình rất hẹp.
- Mobile có panel bộ lọc đóng/mở và `aria-expanded`; kiểm tra không tràn ngang tại 360, 390, 430, 768, 1024, 1366 và 1440 px.
