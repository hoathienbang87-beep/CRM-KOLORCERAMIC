## 4. Chức năng và hợp đồng

### Admin import

- Chọn `Chỉ cập nhật giá` hoặc `Nhập/cập nhật catalog`.
- Excel `.xlsx/.xls` được hash SHA-256, parse theo sheet/header, match theo contract 03A và tạo preview qua RPC 03B.
- Giá hiển thị theo Việt Nam, ví dụ `1.915.000 ₫`; chênh lệch tăng/giảm được đánh dấu riêng.
- Lọc row theo `READY`, `UPDATING`, `CONFLICT`, `EXCLUDED_BY_REVIEW`.
- Candidate chỉ có thể được chọn từ allow-list đã lưu trong provenance của preview.
- Dòng xung đột có thể bị loại; trạng thái batch chỉ thành `READY` khi không còn blocker.
- Approval và apply dùng idempotency key riêng; catalog chỉ đổi sau cả hai bước.
- Lịch sử lọc theo trạng thái; batch `APPLIED` có rollback, backend tiếp tục chặn version conflict.
- PDF không chạy parser cấu trúc hay apply; UI ghi rõ chờ OCR/duyệt thủ công.

### API 06B

- `catalog_admin_list_import_batches_v1(...)`: danh sách/lọc/phân trang batch và summary.
- `catalog_admin_get_import_batch_v1(uuid)`: batch detail + rows cho review.
- `catalog_admin_review_import_rows_v1(uuid,jsonb)`: chọn candidate/loại dòng trước approval.
- Serializer nội bộ bị revoke khỏi browser roles.
- Cả ba API gọi `catalog_require_admin_02b()`; sale/anon bị từ chối.
- Không mở direct write trên `product_import_batches`, `product_import_rows` hoặc `products`.
