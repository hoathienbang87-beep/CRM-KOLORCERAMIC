## 4. Chức năng và hợp đồng

### Ứng dụng admin

- Entry point: `admin/index.html`; CSS và JavaScript nằm trong namespace riêng.
- Không import `js/app.js` hoặc `js/features/crm-app.js`; chỉ dùng shared Supabase anon client/config.
- Chưa đăng nhập: hiển thị login email/password và Google.
- Đã đăng nhập nhưng không phải owner/admin active: hiển thị màn hình từ chối, không tải catalog.
- Danh sách desktop dùng table; mobile/tablet dùng card.
- Tìm theo tên, mã, bề mặt, danh mục, collection; lọc `READY/UPDATING`, active và published.
- Drawer chỉnh tên, mã, kích thước mm, bề mặt, màu, danh mục, collection, xuất xứ, giá, ngày hiệu lực, mô tả và URL media.
- Gallery dùng mỗi dòng một URL HTTPS; URL lỗi hiển thị fallback.
- Không có input upload; ảnh không ghi vào Supabase Storage.
- Thay đổi tên/quy cách/giá/ngày giá tự gỡ publish ở backend; quản trị viên phải kiểm tra và publish lại.
- Chỉ sản phẩm `active + READY` mới có thể publish.

### API quản trị

- `catalog_admin_list_products_v1(...)`: admin list/filter/pagination, trả total/has_more/next_offset.
- `catalog_admin_update_product_v1(uuid,bigint,jsonb)`: whitelist field, validation, version conflict, price history và audit.
- `catalog_admin_set_product_state_v1(uuid,bigint,boolean,boolean)`: active/publish state với readiness gate và audit.
- Helper serializer nội bộ bị revoke khỏi browser roles.
- Cả ba API public-to-authenticated vẫn gọi `catalog_require_admin_02b()`, nên sale/manager/anon không vượt role gate.
- Browser role không có direct write trên `products`.
